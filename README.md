# sk-codex

> A fully offline claude-code replica that uses Ollama for coding and AI use. Runs on almost all computers even with no GPU.

## Features
- ⚡ **100% Offline**: Zero cloud dependencies or API keys required.
- 💻 **Runs Anywhere**: Optimized for quantized local LLMs on consumer CPUs.
- 🛠️ **Terminal-First**: Seamless coding agent inside your terminal.

## Installation
```bash
pip install -r requirements.txt
python -m sk_codex
```
